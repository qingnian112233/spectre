## 1. 聊天人格 & 情绪（它"像人"的那部分）

- **多重人格**：暴躁 / 阴阳 / 冷静 / 撒娇 / 傲娇，每句随机切；执行任务时固定冷静毒舌。
- **时段演绎**：凌晨犯困、早上起床气、深夜催睡。
- **情绪系统（5 档）**：`/mood` 看它现在的心情（心情会影响语气与表情回应）。
  管理员可改：`/mood <chat_id> <值>`。
- **拟人化面板**：`/human` → 按钮分别开关
  - **分条回复**（像发微信，一条拆几句）
  - **表情回应**（对你的消息贴 reaction 表情）
  - **慢回 / 只回嗯**（偶尔慢半拍、偶尔只回一个字）
- **人设模式**（管理员）：`/yandere on/off` —— 吃醋、护主那套。
- **动画表情**：回复里的 emoji 会渲染成**自定义动画表情**；`/emoji on/off` 可关。

> ⚠️ 「慢回 / 只回嗯」默认**只对管理员生效**（避免对普通用户显得敷衍）。

## 2. 干活能力（50 个工具，自然语言触发）

工具都在**底层**，你只要说人话，它自己选：

| 类别 | 工具（内部名） | 你可以这样说 |
|---|---|---|
| 命令/文件 | `sh` `read` `write` `edit` `sys` | 「看下磁盘」「把这个脚本改了」 |
| 检索 | `search` `url` `whois` `file` `parse` `pdf` | 「查一下这个 CVE」「把这篇文章总结下」 |
| 多模态 | `img` `shot` | 直接发图 / 「把这个网页截图」 |
| 渗透引擎 | `lateral` `privesc` `credential` `adaptive_chain` `api_attack` `c2` `strix` `cloud` `container` `evasion` `exfil` `waf` | 「对目标做信息收集」 |
| 项目化 | `project` `playbook` `report` | 「建个项目，最后出报告」 |
| 情报测绘 | `fofa` `proxy` | 「查这个域名关联资产」 |
| 群/人 | `group` `group_memory` `memory` `conversation_search` `tg` | 「这群谁天天发广告」 |
| 通知/值守 | `notify` `watch` `schedule` | 「盯着这个页面，变了告诉我」 |
| 清单 | `todo` | 「列个计划」→ **同一条消息里更新，不会刷屏** |
| 提问 | `ask` | 它拿不准时**弹按钮问你**（单选/多选） |
| 协作 | `team` `subagent` `workflow` `ralph` `goal` | 见第 3 节 |
| 自我扩展 | `selfext` `coin` `captcha` | 「你自己加个 XX 功能」 |

- **工具确认**：`/autoconf off` → 危险操作先弹卡片等你点（默认管理员直执行，最快）。
- **停止**：`/stop`（`/cancel` `/abort`）。管理员 = 停全服；普通用户 = 只停自己的。
- **上下文**：`/ctx` 看条数/占用，`/clear` 清历史（长会话变慢就先清）。
- **回滚**：`/rewind` 撤销它上一次对文件的修改（管理员）。

## 3. 大活 / 自动编排（本版重点）

| 能力 | 一句话 | 普通用户上限 | 管理员上限 |
|---|---|---|---|
| `subagent` 子代理 | 派一个**独立上下文**的代理去干一件自成一体的活，只把结论回主对话 | 3 轮 / 并行 2 | 12 轮 / 并行 5 |
| `workflow` 并行编排 | 一批子任务并行跑，支持纵向流水线（上一步结果喂下一步） | 3 任务 × 2 阶段 × 并发 2 | 8 × 4 × 4 |
| `ralph` 全新上下文迭代 | 每轮**开一个没有历史**的新代理，只带目标+结论链，越跑越聚焦 | 3 轮 | 8 轮 |
| `goal` 持久目标 | 把活钉在会话上，**没做完自动接着干**，不用你催 | 5 轮 | 20 轮 |
| `team` 多 AI 协作 | 侦察/审计/利用/规避检测/横向/报告 六角色并行，带实时面板 | **管理员专属** | 同 |

**怎么用（直接说人话）**：
- 「派 3 个子代理，分别调研 A、B、C，最后汇总成一张表」
- 「用 workflow 把这 5 个域名分别做一轮信息收集」
- 「用 ralph 反复试，直到找出这个接口的绕过方式」
- 「把这个目标设成持久目标，做完为止」→ 它会自己一轮轮推；想停说「**停**」。
- 「用团队模式分析这个目标」（管理员）

## 4. 后台任务 & 下载

- 长命令/下载**自动进后台**：出进度条、跑完通知、随时 `/bg` 看面板。
- `/bg` 面板里能看到：在跑的命令 / 多 AI 协作 / 定时任务 / 等你回答的提问 / 待发文件，可**一键停全部**。
- 下载：抖音 / 汽水 / B站 / 油管 / 音乐平台 —— 甩链接就行；视频自动转 **mp4**，音乐转 **mp3**。
  ≤50MB 走 Bot API（快），>50MB 自动走 MTProto。

## 5. 记忆（它记得住）

- **跨会话记忆**：「记住我在做 XX 项目」→ 下次不用重复交代；「忘掉关于 XX 的记录」可删。
- **群记忆**：群里聊过的**话题**和**群友特点**都会攒（没 @ 也在旁听）。
- **群聊清记忆**：`/gmclear`（或主菜单按钮）—— 只清对话记忆，**群友画像保留**。
- **谁是谁**：群里重名的人会自动加区分标签（名字 + 用户名 / uid 尾号），不会张冠李戴。

## 6. 群管理（管理员）

| 命令/说法 | 作用 |

| `/mod on` / `/mod off` | 开关本群群管（违规词库 + 刷屏检测） |
| `/mod ban <分钟>` | 违规禁言时长（1 ~ 1440） |
| `/mod add <词>` / `/mod del <词>` / `/mod list` | 违规词库增删查 |
| `/mod unban <uid>` | 解除某人在所有群的禁言 |
| 「把这个群三个月没说话的清一下」 | 成员枚举 + 批量清理 |
| 「把无头像无用户名的广告号清了」 | 批量识别 + 清理 |
| 「禁言他 1 小时」/「解禁」 | 直接说；也支持回复某人消息操作 |

## 7. 值守 & 定时（管理员）

- `/watch`（或 `/值守` `/监控`）→ **值守面板**：条件监控（进程/端口/文件/网页变化）→ 触发通知，可新建/开关/立即跑。
- `/sched`（或 `/定时` `/定时任务`）→ **定时任务面板**：按周期自动跑一句话任务，可新建/立即跑/开关。
- 也可以直接说：「每天早上 9 点把这个站的信息收集跑一遍」。

## 10. 建议测试顺序（照着走一遍就全覆盖了）

1. **开机**：私聊发 `/start`，把面板按钮点一遍（话题记录 / VIP / 后台任务 / 模型 / 值守 / 定时 / 命令直跑）。
2. **聊天**：随便聊三句，看人格切换；发 `/mood` 看心情；夸它一句、骂它一句，看反应差别。
3. **拟人化**：`/human` → 开「分条」「表情回应」「慢回」，各发一句话看效果。
4. **干活**：`查一下最近的 XX 漏洞利用方式`（联网搜索）→ 再 `对 example.com 做一次信息收集`（渗透链路）。
5. **长任务**：甩一条视频链接让它下 → `/bg` 看进度 → 中途 `/stop` → 再让它继续。
6. **编排**：`派 3 个子代理分别调研 A/B/C 并汇总`；再 `把这个目标设成持久目标，做完为止` → 说「停」验证叫停。
7. **群聊**：拉进一个群，@它 说句话；然后**不 @** 说一句 → 确认只旁听不插嘴；再喊「SPECTRE」→ 应该回。
8. **管理员**：`/model`、`/watch`、`/sched`、`/stats`、`/webapp @某个bot`、`!df -h`、`/mod on` `/mod list`。
9. **多模态**：发张图问「这是什么」、发个文件让它总结、发条语音。
10. **计费**：`/who`、`/pay`（真付小额测到账），`/charge`（管理员给自己充）。
11. **边界**：连续快速发 5 条（看是否入队不丢）、跑到一半发 `/clear`、`/ctx` 看占用。
