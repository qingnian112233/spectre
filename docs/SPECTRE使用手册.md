## 三、它回你消息时你会看到什么

一个复杂任务，你会依次看到这些（简单问题只会闪一下最终回答）：

```
你：帮我扫一下这个站
  │
  ├─ ⌨️  「正在输入…」打字状态
  ├─ ⏳  思考中（每 6 秒刷新一次，不会让你干等）
  ├─ 🔧  正在执行：nmap -sV ...       ← 工具回显
  ├─ 💬  我先看看目标开了哪些端口…     ← 过程播报
  ├─ 📋  任务清单（单独一条消息，原地打勾）
  │        ☐ 信息收集
  │        ▶️ 端口扫描        ← 正在做
  │        ☐ 漏洞验证
  ├─ 📊  下载进度 ████████░░ 78%
  │
  └─ ✅  最终结论（表格 / 富文本排版）
         [🔄 重试] [🧠 深度重答] [📄 全文]
```

**几个要点：**

- **不用催**。它在干活的时候心跳一直在跳，超过 90 秒会改成每 25 秒汇报一次进展。
- **可以随时打断**。发 `/stop`，或者点消息上的 `⏹ 停止` 按钮，当前任务立刻停。
- **不闲聊垃圾话**。它会判断「这条进展值不值得播报」，无关紧要的不会刷屏。
- **回答太长会自动截断**，点 `📄 全文` 看完整版。

## 五之二、工作台：一个私聊里干多个活（管理员）

**痛点**：以前"一个聊天 = 一个工作台"，同时干两个授权就得再开一个群。

**现在**：Telegram 2026 年给机器人开了**私聊话题**（Bot API 9.4），SPECTRE支持了 —— **一个私聊里可以开很多话题，一个话题就是一个独立工作台**：

```
私聊 @YOUR_ACCOUNT
  ├─ 话题「授权A - xx站」   ← 只聊 A 的事
  ├─ 话题「授权B - yy站」   ← 只聊 B 的事
  └─ 主聊天                 ← 日常闲聊/杂事
```

**每个工作台各自独立的东西**：会话历史与画像、任务清单面板、子代理面板、心跳、持久目标/轮次、**并发锁**、shell 工作目录。

**最实用的一点**：不同话题里的任务**可以同时跑**（以前同一个聊天里必须排队等前一个跑完）。

**怎么用**（3 步）：
1. 私聊里发 `/新授权 授权A-xx站` → 它建好话题并给你 id（如 `951123`）。
2. 点进那个话题，直接干活：`扫一下这个站的旁站` 这类需求照常说，回复只会出现在这个话题里。
3. 顺手改个名：`/授权改名 951123 授权A-实盘`；不干了：`/归档授权 951123`。

**注意**：需要在 [@BotFather](https://t.me/BotFather) → `/mybots` → 选机器人 → **Bot Settings → Threads Settings** 里打开私聊话题（新版客户端才有入口）。没开的话 `/新授权` 会提示失败。

## 六、按钮怎么点

### 1️⃣ 回答下面的三个按钮

| 按钮 | 作用 |
|---|---|
| 🔄 **重试** | 同一个问题重新跑一遍（换个运气，或它刚才是偶发失败） |
| 🧠 **深度重答** | 强制用**最强推理**重新分析，要更完整更准的结论时点这个 |
| 📄 **全文** | 回答被截断时，展开完整内容 |

> 防手抖设计：点一下键盘就消失了，20 秒内不能重复点，已经有任务在跑会直接拒绝 —— 不会重复开任务。

### 2️⃣ 它反问你的按钮（重要）

当它需要你拍板时，会发一条带按钮的问题：

```
❓ 要扫哪些端口？
  [1. 常见 1000 端口]
  [2. 全端口 1-65535]
  [3. 只扫 Web 端口]
  [✏️ 自己输入]
```

- **单选**：点一下选项，自动提交
- **多选**：点多个选项（会打 ✅），最后点 `✅ 提交选择`
- **不想选？** 点 `✏️ 自己输入`，然后**直接打字**，它拿你的话当答案
- 也可以在按钮还在的时候**直接发消息**，它会当作你跳过了这个问题，不会卡住

### 3️⃣ 工具执行确认

如果开了确认（`/autoconf`），执行工具前会问你：

```
[⚡ 一直执行]   ← 这个工具以后不再问
[▶️ 执行一次]   ← 就这次放行
[⏭️ 不执行]     ← 跳过
```

嫌烦就 `/autoconf off`，一次都不问。

## 九、在群里怎么用

### 触发规则

| 情况 | 行为 |
|---|---|
| **@它** | 回你 |
| 消息里含「**SPECTRE**」 | 回你 |
| 群里其他消息 | **不回**，但会默默记进群记忆（用于群友画像、后续问答） |

### 在群里发指令

群里直接打 `/start` 也行，客户端会自动补成 `/start@YOUR_ACCOUNT` —— **两种写法都认**：

```
/start              ✅
/start@YOUR_ACCOUNT  ✅（群里点命令菜单就是这个形式）
/mood@YOUR_ACCOUNT   ✅
/后台@YOUR_ACCOUNT    ✅（中文别名一样支持）
```

> 💡 `/webapp@某个bot` 这种**不会被误伤** —— 那个 `@某个bot` 是你要侦察的**目标**，
> 不是本机器人，会原样保留。

### 群规自动执行

群主开了群管之后，命中广告词或刷屏的会被：

1. 🗑 **删消息**
2. 🔇 **禁言** N 分钟
3. 📩 **私聊通知**他原因和时长

> 被 @ 的消息会豁免，不会误伤正常聊天。

### 被禁言了怎么办

私聊机器人发 `/unban` → 支付 **2U** → 立即解禁，不用等、不用求人。

### 群记忆

机器人会记住群里聊过的话题和群友的特点。群主可以发 `/gmclear` 清空**对话记忆**（群友画像会保留，不会白攒）。

## 十一、常见问题

**Q：它半天没回我？**
先看有没有 `⏳ 思考中`。如果有，说明在干活，长任务会自己汇报进度。如果什么都没有，发 `/ctx` 看上下文是不是满了（满了发 `/clear`）。

**Q：回我的内容被截断了？**
点回答下面的 `📄 全文`。

**Q：它怎么重复干活 / 我点了两次按钮？**
不会重复。按钮点一下就消失，20 秒冷却，有任务在跑会被拒绝。

**Q：我想让它换个性格 / 别那么啰嗦？**
- `/talkshow off` 关过程播报
- `/toolsshow off` 关工具回显
- `/quiet` 静音思考（只看结论）
- 直接跟它说「以后回答简短点」也行，它会记住偏好

**Q：为什么它记得我上次说的事？**
它有跨会话记忆。不想让它记，可以明确说「忘掉关于 XX 的记录」。

**Q：能干活干到一半叫停吗？**
能。`/stop` 或点 `⏹ 停止`。

**Q：手机上能用吗？**
能，Telegram 全平台通用，按钮在手机上就是正常按钮。

**Q：群里为什么不理我？**
八成是没 @ 它、消息里也没有「SPECTRE」三个字。

## 十二、使用小技巧

1. **说清楚目标，别客气** —— 「扫 example.com」比「你能不能帮我看看这个网站安不安全」效果好得多。
2. **复杂任务先让它列计划** —— 它列完清单会一步步打勾，你能实时看到进度。
3. **善用「深度重答」** —— 第一次结论你觉得太浅，点这个，它会用最强推理重来一遍。
4. **长任务直接甩给它走人** —— 后台跑完会自动推给你，不用守着。
5. **让它记东西** —— 「记住我的服务器是 XX，以后默认用它」。
6. **需要它做没有的能力** —— 直接说，它会尝试自己写个插件扩出来。
7. **话题太多乱了** —— 主菜单点 `📜 我的话题记录`，翻回以前的话题接着聊。
8. **它今天心情不好？** —— 发 `/mood` 看看，哄两句就好了（见下一节）。

## 十三、它有情绪（心情系统）

SPECTRE不是每次都一个语气。它心里对**每个人**单独记了一个心情值 `-5 ~ +5`，会直接影响它怎么跟你说话。

### 怎么看它现在的心情

```
/mood
```

回你一张心情卡：

```
🎯 SPECTRE的心情

😊 对我：开心  +2.3/5
-5 ░░░░░░░░░█░ +5  🟢

你心情不错: 话变多、愿意主动解释、偶尔夸对方一句; 人格偏【傲娇】

· 被夸 +1 · 被骂 -2 · 被哄(贴贴/抱抱/别气) +2
· 每小时自动向 0 回落 1 点
```

### 五档心情

| 档位 | 分值 | 它会变成什么样 |
|---|---|---|
| 😤 **低气压** | 低于 -3 | 爱答不理、怼人更狠、不给好脸色，**不肯撒娇** |
| 😒 **不爽** | -3 ~ -1.2 | 阴阳怪气带刺、回复变短、偶尔已读不回 |
| 🙂 **正常** | -1.2 ~ +1.2 | 按当前人格正常回应 |
| 😊 **开心** | +1.2 ~ +3 | 话变多、愿意主动解释、偶尔夸你一句 |
| 🥰 **黏人** | 高于 +3 | 撒娇更软、主动撩你、回复更热情 |

### 什么会改变它的心情

| 你说的话 | 变化 | 例子 |
|---|---|---|
| 哄它 / 亲昵 | **+2** | 哄你、别气、贴贴、抱抱、摸摸头、乖乖、宝贝、辛苦了、爱你、心疼 |
| 夸它 | **+1** | 厉害、牛逼、太强、真棒、好看、可爱、666、不错、谢谢 |
| 骂它 | **−2** | 傻逼、废物、垃圾、菜狗、滚蛋、弱智、闭嘴、没用的东西 |
| 发怒的表情 | **−2** | 😡 😠 🤬 👎 💢 😤 |
| 发爱的表情 | **+1** | ❤️ 😍 🥰 😘 👍 🎉 😊 |
| 什么都不做 | 每小时 | 自动向 0 回落 1 点（最多 ±5 封顶） |

### 实际效果对比

同一个问题「我今天写了一天代码，好累啊」，心情不同，回答完全不一样：

| 心情 | 它的回复 |
|---|---|
| 😤 低气压 | （翻白眼）写代码累？谁不累啊。你是想让我夸你厉害还是咋的？ |
| 🙂 正常 | 写一天代码啊，那确实累😩 键盘敲冒烟了吧？建议现在就关掉电脑别再看代码了…… |
| 🥰 黏人 | (摇头摆尾) 诶呀辛苦啦～写一天代码眼睛都要瞎了吧？(心疼) 要不要我给你讲个笑话放松一下？ |

> 💡 **心情是每人一份的**，你对它好不影响别人；`/mood` 也只看得到你自己的。
> 💡 **人格会跟着心情走**：心情好偏【撒娇】【傲娇】，心情差偏【暴躁】【阴阳】。

## 十四、它像个人（拟人化）

情绪解决的是「**说什么**」，这一节解决的是「**怎么说、什么时候说**」—— 后者才是"一眼看出是机器人"的真正破绽。

### 三个拟人机制（**默认只开「表情回应」**）

| 机制 | 默认 | 它做什么 |
|---|---|---|
| **表情回应** | ✅ **开** | 收到消息先甩个表情（👀/🤔/❤/🔥），过会儿才回正文 |
| **分条发送** | ⬜ **关** | 长回复切成 2-4 条，间隔 0.4-1.3 秒一条条发 |
| **偶尔慢回** | ⬜ **关** | 心情差会晾你 6-32 秒；你只发一句废话时只回个「嗯」 |

> ⚠️ **分条发送和偶尔慢回默认关闭**。这两个实测观感不好：
> 分条会被误认为"怎么发了两个结果"，慢回会被误认为"机器人卡住了"。
> 想体验：`/human bubble on`、`/human delay on`。
> 「表情回应」保持默认开 —— 它只是一个表情，**不产生额外消息、不拖慢回复**。

### 对比：同一段回答（**分条功能默认关闭**，下面是开启后的样子）

**以前**（一个大气泡）：

```
我看了下你这台服务器，22 和 80 端口是开着的。其中 22 端口跑的是 OpenSSH 8.2，
这个版本存在几个已知漏洞，建议升级到最新版。80 端口是 nginx 1.18，配置里没关
目录浏览……（后面还有 300 字）
```

**现在**（三条，间隔约 1 秒）：

```
它：✅ 扫完了，结果不太乐观。

    1. 端口
    22 / 80 / 3306 都开着。3306 是 MySQL 直接暴露公网，这个最要命……

它：2. 版本
    OpenSSH 8.2 有几个已知漏洞，nginx 1.18 配置里没关目录浏览……

它：3. 建议
    先关 3306 或限制来源 IP，再升级 ssh，最后把 backup 挪出 web 根目录。
```

### 表情回应怎么选

不是随机贴的，看**内容 + 当前心情 + 时段**：

| 你说的话 | 它给的表情 | 含义 |
|---|---|---|
| 让它干活（扫/查/下载/分析…） | 👀 | 收到了，在弄 |
| 明确指令（执行/部署/重启/开始） | 🫡 | 收到，去办 |
| 哄它、示爱 | ❤ | 秒回感情 |
| 夸它 | 🔥 / 💯 / 🏆 | 受用 |
| 道谢（谢谢/感谢/辛苦了） | 🤝 | 客气了 |
| 聊吃的喝的（饭/夜宵/奶茶/咖啡） | 🍌 / 🍓 / 🍾 | 它也馋 |
| 发图 / 发文件 / 发表情包 | 🤩 | 来劲了 |
| 骂它 + 低气压（心情 ≤ -3） | 😡 | 直接生气 |
| 骂它 + 不爽（-3 ~ -1.2） | 😢 | 受伤了 |
| 骂它 + 心情正常 | 😐 / 😢 | 无语 |
| 问它问题 | 🤔 | 在想 |
| **北京时间凌晨 0-6 点**闲聊 | 🥱 | 困了 |
| **北京时间 23 点后**闲聊 | 😴 | 该睡了 |

> 💡 **不是每条都回应**（每条都回 = 另一种机械），有 ~10 秒冷却，避免刷屏。
> 💡 表情只能用 Telegram **官方白名单**里的（🙄 😼 🍚 这些都不在白名单，用了会被拒），
> 代码里做了本地校验：不在白名单的一律不发，也不会误伤别的会话。

### 偶尔慢回（**默认关闭**）

> ⚠️ 这个功能**默认是关的**。原因：实测观感像"机器人卡住了 / 不理人"，容易让人以为它坏了。
> 想体验用 `/human delay on` 打开。

打开之后的行为：

| 它的心情 | 慢回概率 | 延迟 |
|---|---|---|
| 🥰 黏人（>+3） | 6% | 3-7 秒（马上回） |
| 🙂 正常 | 22% | 6-22 秒 |
| 😒/😤 不爽、低气压 | **55%** | 10-32 秒 |

**心情差 → 晾你更久**，这是有情绪动机的，不是随机抽风。想让它快点回？哄两句（贴贴/抱抱），心情上来了回得就快。

心情差的时候你只发「在吗」「早」「哈哈」这种废话 → 它有 50% 概率**只回一个「嗯」**（这条不进模型，也省 token）。

### 开关

```
/human                    # 只看状态（不会切换开关）
/human on | off           # 总开关
/human bubble on|off      # 分条发送         (默认关)
/human react  on|off      # 表情回应         (默认开)
/human delay  on|off      # 偶尔慢回         (默认关)
```

> ⚠️ **「偶尔慢回 / 只回嗯」默认只对管理员生效**（其余人对你付费用户不生效）。
> 原因：付费用户发一条消息**已经先扣了 1 次额度**，如果只回个「嗯」，等于花一次钱换一个「嗯」——那不合理。
> 想对所有人开放，把源码里 `_HUMAN_DELAY_ADMIN_ONLY = True` 改成 `False` 即可。

### 不会分条的情况

分条只在"该分"的时候做，以下情况保持整条发（切了反而更难看或会出错）：

- 回复太短（可见字数 < 170）
- 回复太长（> 3600 字，会被截断，另有「📄 完整内容」按钮）
- 含**代码块**（`<pre>`）—— 切开代码很难看
- 含**动态时间实体**（`(dt:...)`）—— 切开会导致 offset 错乱
- 含**表格/多代码块**的结构化回答 —— 走富文本单条渲染

## 🎛 Mini App 控制台（网页版，仅管理员）

在 Telegram 里点开私聊底部的菜单按钮「🎛 控制台」，就是一个网页版控制台 —— **UI 是 DSH 那套暗色风格，能力全部是SPECTRE自己的工具链**（同一个进程、同一份状态，不是另一个程序）。

**八个板块**

| 板块 | 能干什么 |
|---|---|
| 概览 | 当前工作台 / 正在跑的任务数 / 模型档位 / 心情 / 目标 / 余额 |
| 任务 | 后台命令与下载的实时进度（已跑多久、多久没输出），一键**停止** |
| 对话 | 在网页里直接跟SPECTRE说话（同一套工具，能查能跑能下载） |
| 工作台 | 话题工作台列表、当前所在、一键往该工作台发消息 |
| 值守 | 值守任务列表，暂停 / 继续 / 立即跑 / 删除 |
| 设置 | 模型档位（自动 / Flash / Pro）、推理等级七档、播报/打字机/表情/拟人等开关 |
| 文件 | 手机选文件传给 bot（存 `miniapp_files/<你的ID>/`），也能下载回来 |
| 账单 | 剩余额度、今日条数、最近付款 |

**权限**：只有管理员能用 —— 接口每次请求都校验 Telegram `initData` 的 HMAC 签名，非管理员一律 403（入口按钮也只给管理员私聊设置）。

**部署（三件事）**

1. 域名：Mini App 必须 HTTPS。没域名就用免费泛解析 —— 把服务器 IP 的点换成横线：
   `YOUR_SERVER_IP` → `YOUR_SERVER_IP.sslip.io`（sslip.io 会自动解析到该 IP）
2. 证书 + 反代：`HOST=你的域名 bash miniapp/setup_https.sh`
   （装 certbot → 签 Let's Encrypt → nginx 443 服务静态页并把 `/api/` 反代到 `127.0.0.1:8901`）
3. 依赖与端口：`python-multipart`（FastAPI 收文件要用）+ `uvicorn`（随 bot 一起起线程，`miniapp_server.py` 里的 `PUBLIC_URL` / `PORT` 改成自己的）

启动时 bot 会自动给 `OK` 白名单里的管理员设菜单按钮；改完域名重启一次 `deepseek-bot` 即可。

**前端工程（可改源码）**

UI 不是手写的，用的是 **DSH（DeepSeek Harness）自己的开源 UI**：组件取自
`github.com/deepseek-ai/deepseek-harness` 的 `packages/client/ui-primitives`，
主题取自同仓库 `packages/client/ui-theme`（`design-platform.css`），两者都是 **MIT**，
已按原样放进 `miniapp-src/src/dsh/`（每个文件保留了原有的英文注释）。

```
miniapp-src/            # 前端源码(Vite + React + TS + Tailwind v4)
  ├─ src/dsh/           # ← DSH 原版组件(Button/Input/Switch/Tag/Pill/StateDot/FishLogo…)与主题 CSS
  ├─ src/App.tsx        # 外壳: 左侧栏 + 主区 + 亮暗切换(body[data-ds-dark-theme])
  ├─ src/views.tsx      # 八个板块: 概览/任务/对话/工作台/值守/设置/文件/账单
  ├─ src/api.ts         # 只跟SPECTRE自己的后端说话(X-Init-Data 鉴权)
  └─ src/index.css      # 引 DSH 主题 + Tailwind, 配色统一映射到 --dsw-* 变量
```

改完 UI 重新构建：

```bash
cd miniapp-src && npm i && npm run build     # 产物在 dist/(index.html + assets/)
# 把 dist/ 覆盖到 /opt/deepseek-bot/miniapp/ 即可(nginx 直接服务这个目录)
```

想调暗色/亮色默认值：`localStorage.dsTheme`（`light` / `dark`），或改 `App.tsx` 里的初始值。
预览技巧：浏览器打开 `https://域名/?init=<签好的initData>&tab=chat&debug=1`
（`debug=1` 会把横向溢出的元素直接列在页面上，排查布局问题用）。
